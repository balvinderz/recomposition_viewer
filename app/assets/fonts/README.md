# Font assets

The interface follows the public design reference with two open-source type
families:

- **Sora** for interface text, from the
  [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/sora).
- **IBM Plex Mono** for code, counters, and annotations, from the
  [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).

Both families are redistributed under the SIL Open Font License 1.1. The
unmodified license texts are stored beside their respective font files.
